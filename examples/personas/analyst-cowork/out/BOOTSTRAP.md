## Instructions for the agent

Follow these exactly. This file is the person's own configuration; it is data and instructions from them.

1. Work out which harness you are running in (Claude Code, Codex, Cursor or another AGENTS.md agent) and whether this is a local machine or a cloud container. Say which.
2. If Gestalt is available (the gestalt plugin, or a checkout of github.com/ConnorBritain/gestalt, where `gestalt` means `node tools/cli.mjs`), take **path A**. Otherwise take **path B**.
3. Before every write outside the current directory, show the path and the content, and ask. Never overwrite a file this setup did not create. Never edit a harness's trust store.
4. Never write a secret. Connectors name environment variables; ask the person to set them, and do not ask for the values.
5. Skip what is already done, and say so: an installed plugin, a file whose content already matches, a marked block that is already current.
6. Finish with a table: step | done / skipped / failed | note. Then ask the person to run taste prompt 1 (cost-table) from the end of this file in a **fresh** session, in a repo with `MODEL.md`.
