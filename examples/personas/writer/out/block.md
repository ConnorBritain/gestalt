## Way of work   <!-- gestalt -->

Order: orient → intend → plan → make → check → record. Checkers report; they never fix. Give every worker and critic the user's original request verbatim and the decisions made since.
- Before calling non-trivial work done: prose-tell-scan scan → prose-review review.
- Route gathering sources for an issue, each with a link and a date → `sh ~/.gestalt/build/workers/research.sh "<task>"`.
- Route reviewing a finished draft before it is sent → the prose-review critic, as its own agent in fresh context.
Trivial turns (typo, version bump, a one-line fix) skip these gates; say so when you do.
